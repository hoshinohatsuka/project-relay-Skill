# Iteration Report — project-relay v3.0.0「模式D 借鉴计划」（2026-09-15）

## 1. 本次来源与动机

用户的"借鉴计划"新想法：现有模式A（单目标拆解）与模式B（单目标接手）之间存在**结构性盲区**——真实场景常同时面对"自己的项目"与"想借鉴的项目"，需要双目标配对、独立双线扫描、对比差异出借鉴点、并在许可证与版权边界内决定"抄还是不抄"。用户拍板 5 项决策：命名"模式D 借鉴计划"、版本 v3.0.0（重要新方向）、许可证检测三级且默认更深、借鉴点档位上限（快速≤8/标准≤20）、"抄代码"默认仅理念需显式选择。实施基线：远程 v2.2.0（a37c0d9，已同步至本地开发副本）。

## 2. 设计决策与处置

- **模式D 落为 D0–D8**：D0 目标定性（双项目登记表 + 角色锚定，不明确立即停下问，绝不猜——防锚定反转）→ D1 双线独立扫描（参考方走 A 的 P1–P4，用户方走 B 的 H1，结论互不共享）→ D2 对比扫描（以「需求→模块」映射对齐，非全量 diff，双端 file:line 可回溯）→ D3 借鉴点提取（类型/来源 SHA+file:line+证据级/用户落点/工作量，无落点标 `[待定位]`）→ D4 借鉴计划（C>C>M>P + Vertical Slice + 沿用用户方禁区）→ D5 社区调研（复用 P6 九平台）→ D6 解耦/性能门 → D7 安全门（许可证三级判定 + 意图询问）→ D8 汇总（BORROWING_PLAN.md，批准后接 H6）。
- **差异化论证**：模式D 不是 A+B 拼盘，核心新增为 D2（双项目映射对齐）与 D3（来源→落点双向绑定），以及 D7（许可证与意图门禁）。
- **许可证三级判定**（采纳"默认更深"）：① 声明级 L2（读 LICENSE/README）→ ② 缺失/矛盾升级（missing evidence + 问用户，不假定）→ ③ 用户拍板（常识兼容表，恒标"非法律意见"）。`scripts/check_license.py` 只做结构检测（LICENSE 存在性/SPDX 提取/声明确认/矛盾与缺失报告），不做法律判断——延续"脚本只管机器可判定的结构"哲学（v2.0.0 决策）。
- **意图询问**：默认安全路径=仅理念借鉴（架构/设计/接口形态，重写实现）；"抄代码"为高风险路径，需用户显式选择且许可证判定通过。
- **门禁配套**：SKILL.md 压缩腾空间（14,077→13,985 B，删模式表、黑板协议压成三段、八条不变量下沉 relay-principles 为一行摘要）；trigger_cases.json 新增 borrow_action 概念组与 10 例（48 例全过）；evaluate_triggers.py 分母封顶 min(5,max(3,n))（对齐乔木评测器，防止第 7 组稀释 2-命中最小正信号）；validate_skill.py 新增模式D 标记/接口 token/场景覆盖；scenario_matrix.json + EVALUATION_PLAN.md 增 D 双场景（角色锚定 + 许可证门禁）。
- **顺带修复（2.2.0 遗留）**：reports/skill-ir.json 重导出 2.1.1→3.0.0；README 中英拆分导致的 3 条门禁警告（Troubleshooting 标题、验证命令区、上游归因原文）；README 安装区仓库名不一致（方式二/三指向不存在的 `project-relay`）；.gitignore 重建（v2.2.0 误删，现隔离 .zcode/参考资料/oss-teardown/拆解分析）。

## 3. 对抗式审查（对 v3.0.0 成品）

1. **"模式D 是 A+B 拼盘"** → D2/D3 产物（映射对齐差异表、来源→落点）列入冒烟验收硬指标；无差异表/借鉴点清单即视为未完成。
2. **"许可证判定不可靠/是法律问题"** → 降级为声明级+常识表+必问用户；脚本零法律判断；GPL→非 GPL 强制升级。
3. **"借鉴点清单流水账"** → 档位上限（≤8/≤20）+ 每条双端可回溯 + 无落点标 `[待定位]`。
4. **"14KB 预算已超"** → 压缩列为实施第一步（实测 13,985 B < 14,000）。
5. **"用户分不清哪个是项目"** → D0 硬门禁，产物头恒带双项目登记表。
6. **"角色锚定反转"** → 登记表 + SKILL.md 失败模式速查新增行"模式D 角色搞混 | D0 未锚定前不启动任何引擎"。
7. **"第 7 概念组稀释触发评测"** → 分母封顶 + 旧 38 例回归（48/48 全过，0 FP/0 FN）。
