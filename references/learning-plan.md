# 教学模式（模式E）操作细则

对应 SKILL.md 模式E。**第一性原理**：学习 = 把"项目是什么"翻译成"用户按什么顺序、用什么例子、做什么练习，才能独立看懂并复刻它"。模式A 回答"它是什么"（分析报告），模式E 回答"**我该怎样学会它**"（教学课程）——引擎同 A（P1–P6 复用），差异在教学编排与思维引导。**先例**：repo-learner-suite（MIT）的 global→local 认知流与 Use→Modify→Debug→Create→Compare 练习阶梯被吸收；其 Jupyter 脚手架/mock 验证/交互式 HTML 因与本技能安全边界#1（不运行目标代码）冲突而 reject；三思维清单教学法、小白分档、review/性能思维教学为 invent。

## E0 目标确认（硬门禁，不可跳过）

1. **项目地址**：用户未给明确地址 → **先询问**（本地克隆仓库路径或 GitHub 链接，二者取一，都有更好）。绝不猜地址。
2. **学习者水平**：默认**小白**；用户可指定"入门/进阶"。水平决定生词表密度与阶段粒度（小白每阶段必带生词表 + 前置清单；进阶可跳过 30 分钟入门课）。
3. **学习目标**：默认"全部"（语言/架构/产品思路）；可聚焦（"只学认证设计"→ 学习地图只覆盖相关模块，其余标"本次不学"）。

## E1 教学化侦察

复用模式A 的 P1（克隆侦察+commit SHA）、P2（基线测绘四层）、P3（需求→模块映射）。**额外产出依赖序**：对每个需求/模块标注"要理解它，必须先懂 A、B"——这是学习地图的拓扑基础。依赖序有环（模块互相依赖）时标 `[循环依赖]`，学习时先按入口→数据流方向破环。

## E2 学习地图（核心）

按 E0 的水平与目标编排四阶段（默认）：

| 阶段 | 时长 | 内容 | 产出 |
|---|---|---|---|
| ① 认识项目 | 30 分钟 | 一句话定位 + 最小鲜活例子走读（真实代码 file:line 逐行走） + 语言/框架/前置知识清单（每项带"去哪补"） + 生词表（≤10 个术语白话解释） | 用户能向别人复述"这是什么" |
| ② 核心链路 | 2 小时 | 数据流图（Mermaid）+ 主流程文件列表（file:line）+ 一次端到端走读（入口→主流程→输出） | 用户能画出主线 |
| ③ 一个模块深读 | 1 天 | 选一个与学习目标最相关的模块：选型矩阵（证据分级）、解耦评估、该模块的鲜活例子 | 用户能复述该模块为什么这样设计 |
| ④ 复刻子集 | 1 周 | 挑最小可运行子集，用户在自己 IDE 复刻（本技能不运行目标代码，练习在用户环境完成） | 用户有可运行成果 |

**鲜活例子规则**：每个阶段至少一个"真实代码最小样例"——从目标项目挑一个函数/文件（file:line + commit SHA），带用户逐行走读；禁止用抽象讲解替代真实代码。例子是**引用**（只读分析），不是执行。

## E3 三思维清单（教学法核心，每条必绑证据）

| 清单 | 默认条数 | 条目格式 | 引导动作（不代答） |
|---|---|---|---|
| **第一性原理清单** | 5–8 | "项目真正解决的底层问题 → 为什么这样设计（file:line）" | 让用户复述："如果是你，先解决哪个问题？" |
| **对抗式审查清单** | 5–8 | "如果我要故意让项目失败，从哪里攻击（file:line 攻击面）" | 引导用户**自己举例**另一种攻击，AI 只反馈"你的攻击会不会打到这行代码" |
| **墨菲清单** | 5–8 | "最可能在何时炸、怎么防护（绑定模块/文件）" | 引导用户反思自己写代码的对应场景 |

教学纪律：清单是**提问引导**不是知识灌输；每条必须能回溯到项目证据（file:line 或外部来源 URL+日期），无证据条目不算数（复用 P7 复核）；AI 不给"标准答案"，只给证据与框架，答案与联想由用户产出。

## E4 举一反三练习（Use→Modify→Debug→Create→Compare 阶梯）

| 档位 | 练习数 | 组成 |
|---|---|---|
| 快速 | 3–5 | 至少覆盖 Use + Modify + Create |
| 标准（默认） | 8–12 | 覆盖全部五级 |

- **Use**：用现成例子改参数/配置，观察变化（引导问题，如"改这个阈值会怎样"）。
- **Modify**：改一个模块的接口/行为（给"改哪里、影响哪些模块"的引导）。
- **Debug**：给一个"故意弄坏"的场景（本技能**不运行目标代码**——场景以描述形式给出，用户在自己的环境复现与修复）。
- **Create**：实现一个同构小功能（提示骨架，不给完整答案）。
- **Compare**：把 X 换成 Y（另一框架/库），问"会影响哪些模块、为什么"（迁移思维）。
- 每个练习：**提示**（≤3 条引导）+ **验收标准**（可判据："你的实现能处理边界输入 X"）+ **不代答**。AI 的反馈限于"你的实现会不会破坏 A 模块"式校验，不直接给出代码。

## E5 社区学习调研

复用模式A P6 与 community-research.md 的九平台与预算规范。学习场景额外查询（见 community-research.md 第 6 节）：`<项目> tutorial`、`<项目> 入门 教程`、`<项目> 踩坑`、`<作者> 教学 视频`。每条按规范记录（查询/URL/日期/来源/可访问/结论）；搜索摘要只作线索；推荐给用户的资源标注"来源类型"与"可能过时（>2 年）"。

## E6 解耦 + review/性能思维教学

- **可 review 结构**：学习资料按"接口边界 / 依赖方向 / 可测试性 / 替换成本"四问整理——教用户"以后自己审批自己代码"时从哪四问入手。
- **性能思维**：教"怎么看一个项目卡不卡"——静态风险（同步 IO 进事件循环/N+1/重复计算/缓存缺失/大文件进内存/冷启动）→ 可验证假设 → 真实 benchmark；每项给"从哪入手优化"的一句话修法。默认不运行目标代码；性能结论标注证据等级。

## E7 汇总与交接

产出 `LEARNING_PATH.md`（模板 17）：
1. 小白向 TL;DR（三句话能说清"这是什么、学什么、怎么学"）
2. 学习地图（四阶段 + checkbox + 每阶段产出验收）
3. 前置知识清单 + 生词表
4. 鲜活例子索引（file:line + SHA）
5. 三思维清单（第一性原理/对抗式/墨菲，每条绑证据）
6. 举一反三练习（阶梯 + 提示 + 验收，不代答）
7. 社区学习资源（含 missing evidence）
8. 覆盖率分母与未分析范围
9. **切模式A 入口**："想要深度拆解报告 → 说'改用模式A'"。

## 模式E 专属失败模式

| 失败 | 检测 | 恢复 |
|---|---|---|
| 地址缺失 | E0 询问 | 本地/链接二者取一，不猜 |
| 链接失效/私有 | E0 预检 | 转问本地路径 |
| 小白被术语淹没 | 阶段生词表 | 前置清单 + "去哪补" |
| AI 代答练习 | 输出审查 | 只给提示；反馈限校验式 |
| 项目超大（>500 模块） | 档位降级 + focus | 先学核心 30%，如实声明 |
| 三清单空泛 | 每条必绑证据 | P7 复核增加该项 |
