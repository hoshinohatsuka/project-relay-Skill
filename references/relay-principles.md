# 接力原理：本技能的设计公理

来源：作者（hoshinohatsuka/星野白夜）与 @钰 的跨模型接力实战方法、"项目接手" GPT 对话的协议化综合、第二思考（另一 AI 的 v2 评审）的八不变量，以及生态先例（Cline Memory Bank、agents.md、AI Hero /handoff、Together AI plan-divide-conquer）。每条公理都对应 SKILL.md 中可审计的机制。

## 十条思想

1. **项目即记忆，模型即 CPU**。模型会换、上下文会丢、额度会用完；把可执行记忆写进仓库（run 目录 / `.ai/`），模型不再充当项目的记忆载体。→ 机制：黑板文件 + 交接包。
2. **认知外包给结构，不外包给智力**。执行质量 = 模型智力 × 状态掌握 × 上下文完整性 × 执行纪律；后三项可被协议工程化，所以"精致规划能让便宜模型做完大项目"。强模型建立认知，弱模型执行已结构化的认知。→ 机制：模式B 的交接包 + 十项属性模块卡。
3. **真相层级是多 Agent 协作的宪法**。两份扫描可能都错，仲裁序必须超越任何 AI 报告："AI 报告 vs AI 报告"不够，必须"vs 项目事实"。→ 机制：真相层级表。
4. **先独立侦察，再对比交接**。接手者先盲扫形成自己的认知，再与前任认知对比——差异处即风险处。→ 机制：H1 顺序不可换。
5. **不确定性显式记账**。五类复述 + 假设登记表，让"不知道"成为一等公民，防止推测伪装成事实传染给下一位。→ 机制：五类复述模板 + ASSUMPTIONS.md。
6. **执行纪律 = 顺序 + 禁区 + 检查点**。Correctness > Completeness > Maintainability > Performance；变更禁区防"顺手重构"雪崩；Vertical Slice 保证每阶段可运行；git checkpoint 是 AI 的事务机制。→ 机制：H4/H6。
7. **审查协议化而非口号化**。第一性原理/对抗式/墨菲/联网调研各变成一个具体问题 + 预算，防止过度审查空转不写代码。→ 机制：P7 + H4 四问。
8. **信息源分层**。官方文档 > 官方仓库 > 规范 > 高质量开源 > SO/博客 > 社区短帖；社区内容适合问"有什么坑"，不适合定"事实是什么"。→ 机制：P6 优先级表 + H4 分层。
9. **持久化黑板 + 最小完备交接**。跨时段协作的关键不是同时多少 Agent，而是每次交接写出最小完备状态（目标与 SHA、任务状态、证据、失败、下一步），Agent 间传路径+摘要不传大段文本，避免传话失真与上下文爆炸。→ 机制：run-manifest/task-ledger/evidence-ledger。
10. **接力闭环**。强模型建立认知 → 交接包写入仓库 → 弱模型独立侦察 → 对比冲突按真相处决 → 测试证明 → 更新状态 → 下一位。测试负责证明"认知没有骗人"。
11. **文档权威于意图与状态，代码权威于事实**。模式C 交接文档自称"唯一权威进度记录"时，权威只覆盖"做到哪、要什么、什么不能动"；一旦涉及"代码实际是什么"，仍按真相层级由代码裁决。C 写合约，B 验合约。
12. **红线穿越工具边界**。交接文档中的红线是经离场者转述的用户授权边界，换模型、换工具、换会话都不失效；接手者可以请用户解除，不能自行解除。多模型/多 Agent 并行副本交叉验证（各领副本、互不污染、非作者互审、证据择优）是抑制单一模型幻觉积累的工程化手段，但只用于"错了很贵"的关键项。

## 八不变量（审计口径）

事实可回溯 / 需求映射模块 / 选型理由分级 / 热度≠质量 / 多 Agent 扩宽度不产重复文本 / 跨时段靠持久产物 / 失败从 checkpoint 恢复 / 目标是学习复刻。全部落到 SKILL.md 与 P0–P8、H0–H7 的具体动作上；任何一次修改本技能，先检查八条是否仍然成立。

## 已知边界（诚实声明）

- 弱执行者并非免费：失败可检测且重试便宜时省钱，否则重试会吃掉差价（生态共识，见 Together AI plan-divide-conquer 与模型路由文章的反方观点）。
- 静态四路扫描不承诺零遗漏，只承诺报告已检查与未知范围。
- 静态性能审计给的是风险与假设，不是 benchmark。
- 自动触发是否生效属于宿主行为，本地评测只能证明描述匹配，需真实会话冒烟，否则记 missing evidence。
